# Лабораторна 1. Аналіз зацікавлених осіб. RACI матриця

## 1. Заповнити RACI матрицю

R - виконує роботу; А - відпоавідає за результат; С - консультує; I - інформуємо щодо результатів

Можливі комбінації: AR, CI

В комірках зазначаємо класи зацікавлених осіб. Можна використати перелік з лекції та/або його розширити

| --- | --- | --- | --- | --- |

| Elicitation |  |  |  |  |
| Requirement analysis |  |  |  |  |
