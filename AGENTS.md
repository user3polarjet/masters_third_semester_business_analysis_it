# Project instructions

## Лабораторні звіти

- Структурувати кожен Typst-звіт однаково:
  - `= Мета`
  - `= Завдання`
  - `= Виконання`
  - `= Висновок`
- Не створювати окремі розділи першого рівня для частин виконання на кшталт `SWOT-аналіз`, `Реєстр ризиків`, `Варіант використання`, `Опис канви`, `BPMN-модель` тощо.
- Усі такі частини оформлювати як підрозділи всередині `= Виконання` через `==` або, за потреби, `===`.
- У розділі `= Мета` не повторювати фразу `Мета роботи - ...`. Формулювати одразу дією, наприклад: `Описати функціональні вимоги...`.
- Таблиці дозволяти розривати між сторінками. Для таблиць із заголовками використовувати `table.header(...)`, щоб шапка повторювалась після розриву.
- Не додавати автоматичний напис `Продовження таблиці ...`, якщо користувач окремо цього не попросить.
